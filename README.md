
# Sittuyin ML Engine

An open-source Sittuyin learning and playing platform
featuring a custom-built Burmese chess engine and
machine learning research pipeline.

## Project Vision

Promote Sittuyin, the traditional Burmese chess variant,
through an accessible digital learning and playing platform.

The project also explores applied machine learning,
game search algorithms, data processing, and neural
network-based position evaluation.

## Core Features

- Learn Sittuyin
- Play Sittuyin
- Play against a custom-built Sittuyin engine
- Collect and process game data
- Train and evaluate ML models

## Technology Stack

- Frontend: React, TypeScript, Vite
- Backend: Python, FastAPI
- Database: PostgreSQL
- Game Engine: Python
- Machine Learning: PyTorch
- Data Processing: NumPy, Pandas
